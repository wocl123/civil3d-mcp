My Civil 3D MCP 사용 안내

[설치하기]
1. https://github.com/wocl123/civil3d-mcp/releases/latest 를 엽니다.
2. MyCivil3DMcp-버전-win-x64.exe를 다운로드합니다.
3. Civil 3D와 AutoCAD를 종료하고 EXE를 실행합니다.
4. [설치 / 업데이트]를 누른 뒤 [완료]를 누릅니다.
5. Civil 3D 2025를 실행하고 사용할 AI 계정에 로그인합니다.

[자동 업데이트]
GitHub에서 서명된 새 버전을 확인하고 Civil 3D 종료 후 설치합니다.
사용자 데이터와 AI 로그인 설정은 유지합니다.
기존 Drive 설치본은 새 EXE로 한 번 설치해야 GitHub 업데이트가 연결됩니다.

[데이터 전송]
설치본에 포함된 관리자 웹앱 수신 설정으로 비식별 기록을 자동 전송합니다.
사용자 Google 로그인, Drive 앱 설치, 폴더 공유, 경로 설정은 필요 없습니다.
팔레트 /중앙에서 전송 상태를 확인하고 보내기를 끄거나 켤 수 있습니다.
관리자 PC가 꺼져 있어도 웹앱이 비공개 Drive 데이터 폴더에 받습니다.
자동 업데이트와 데이터 보내기는 별도로 동작합니다.

[문제가 생겼을 때]
실행 중인 프로그램 안내가 나오면 종료 후 다시 시도합니다.
설치 파일 검증 오류는 위 GitHub 저장소에서 EXE를 다시 받습니다.
Windows 게시자 서명은 아직 없어 경고가 나타날 수 있습니다.
