# 중앙 서버 설정 가이드

중앙 서버를 노트북 같은 PC 한 대에 띄운다. 다른 PC들은 팔레트에서 그 주소로 연결한다.
데이터를 어떻게 다루는지는 [데이터관리_설계.md](데이터관리_설계.md)에 있다.

## 1. 서버 PC(노트북) 준비

1. **Node.js 설치**
   - https://nodejs.org 에서 LTS(20 이상)를 설치한다.
2. **폴더 복사**
   - 이 저장소를 노트북에 받는다(git clone 또는 폴더 복사).
   - 서버에 필요한 것은 `central\` 폴더뿐이다.
3. **서버 시작**
   - `central\start-central.bat`을 **마우스 오른쪽 → 관리자 권한으로 실행**한다.
   - 처음 실행할 때는 필요한 도구를 설치하고 빌드한다.
   - `settings.json`을 만들고, 방화벽에서 포트를 연다(개인·도메인 네트워크만).
   - 관리자 권한이 아니어도 서버는 뜬다. 다만 방화벽이 막혀 다른 PC가 접속하지 못할 수 있다.
4. **창에 나온 안내 확인**
   ```text
   my-civil3d-mcp central server: http://192.168.0.25:48950
     각 PC의 팔레트에서: /중앙 연결 http://192.168.0.25:48950 928f95fe...
     검토자 키: ...\central\data\config.json의 reviewerKey
   ```
   - `/중앙 연결 …` 한 줄을 사용자들에게 전한다.
   - 서버를 켜 두는 동안 이 창은 닫지 않는다. 끌 때는 Ctrl+C를 누른다.

## 2. 설정 파일

### `central\settings.json`: 서버를 운영하는 사람이 고친다

```json
{
  "host": "0.0.0.0",
  "port": 48950,
  "dataDir": "data"
}
```

| 항목 | 뜻 |
|---|---|
| `host` | `127.0.0.1`이면 이 PC에서만 접속된다. `0.0.0.0`이면 같은 네트워크의 다른 PC도 접속된다. |
| `port` | 다른 프로그램이 이미 쓰고 있으면 바꾼다. 바꾼 뒤에는 방화벽도 다시 열어야 한다(스크립트를 관리자 권한으로 다시 실행). |
| `dataDir` | 데이터 폴더다. 상대 경로는 `central\` 기준이다. 예: `D:\\civil3d-central-data`. |

고친 뒤에는 서버를 껐다가 다시 켠다.

### `<dataDir>\config.json`: 키와 통계 기준(처음 시작할 때 자동으로 만들어짐)

| 항목 | 뜻 |
|---|---|
| `enrollKey` | 가입키다. 사용자에게 준다. 바꿔도 이미 연결된 PC는 그대로 쓴다. 새로 연결하는 PC만 새 키가 필요하다. |
| `reviewerKey` | 검토자 키다. 검토자에게만 준다. 바꾸면 검토자가 `/중앙 검토자 <새 키>`를 다시 입력해야 한다. |
| `minInstalls` | 설정값을 제안하려면 서로 다른 PC가 몇 대 필요한지(기본 2) |
| `minCases` | 설정값을 제안하려면 수정이 몇 건 필요한지(기본 5) |
| `minShare` | 해당하는 수정 중 이 비율 이상이 같은 방향이어야 제안한다(기본 0.8) |
| `reportDays` | `/검토 보고`에 보여 줄 기간(일, 기본 30) |

키는 비밀번호처럼 다룬다. `config.json`은 저장소(git)에 올라가지 않는다.

## 3. 각 PC에서 연결(팔레트 채팅창)

| 할 일 | 입력 |
|---|---|
| 처음 연결 | `/중앙 연결 https://192.168.0.25:48950 <가입키> <인증서지문>` (서버 창에 그대로 나온다. 설치 묶음으로 설치한 PC는 자동) |
| 상태 보기 | `/중앙` |
| 검토자 PC로 지정 | `/중앙 검토자 <검토자 키>` |
| 지금 바로 보내고 받기 | `/중앙 동기화` |
| 보내기 멈춤 / 다시 시작 | `/중앙 끊기` / `/중앙 켜기` |

서버가 꺼져 있어도 각 PC에는 아무 문제가 없다. 기록은 PC에 쌓였다가 서버가 다시 켜지면 자동으로 보내진다.

## 4. 노트북 주소가 바뀌었을 때

노트북은 와이파이에 따라 IP가 바뀐다. 서버 창 첫 줄에서 새 주소를 확인한다.
그다음 각 PC에서 아래 명령으로 **주소만** 바꾼다. 다시 가입할 필요는 없다.

```text
/중앙 주소 https://192.168.0.31:48950
```

- 새 주소에서 이 PC의 등록을 확인한 뒤에만 바꾼다. 확인하지 못하면 주소는 그대로 둔다.
- 주소가 자주 바뀌면 공유기에서 노트북에 고정 IP(DHCP 예약)를 주는 것이 편하다.

## 5. 서버를 다른 PC로 옮길 때

1. 지금 서버를 끈다(Ctrl+C).
2. `central\data` 폴더를 통째로 새 PC의 같은 위치(또는 `dataDir`로 정한 위치)에 복사한다. 등록된 PC, 기록, 후보, 중앙 지식, 키가 모두 이 폴더에 있다.
3. 새 PC에서 `start-central.bat`을 관리자 권한으로 실행한다.
4. 각 PC에서 `/중앙 주소 <새 주소>`를 입력한다. `data\tls`도 함께 옮겼으므로 인증서 지문은 그대로다.

`data` 폴더를 옮기지 않고 새로 시작하면 새 키가 만들어진다. 이때는 모든 PC가 `/중앙 연결 <주소> <새 가입키>`로 다시 연결해야 한다.

## 6. 보안

다른 PC가 접속하는 설정(`-AllowNetwork`, host 0.0.0.0)에서는 아래가 자동으로 적용된다.

| 위험 | 대책 |
|---|---|
| 통신 엿보기·가로채기 | **HTTPS만** 쓴다. 처음 시작할 때 사내용 인증서를 만들고(`data\tls`), 각 PC와 설치 프로그램은 그 인증서 **지문(SHA-256)만** 믿는다. 지문이 다르면 아무것도 보내지 않는다. 다른 PC로 가는 HTTP는 거절한다. |
| 설치 파일 바꿔치기 | 릴리스는 GitHub에서 **서명**한다(비밀 키는 GitHub Secret과 관리자 PC 백업에만). 설치 프로그램은 번들 서명을, 중앙 서버는 zip 서명을 공개 키로 확인한다. 서버가 해킹돼도 가짜는 설치되지 않는다. |
| 키·토큰 파일 유출 | `data` 폴더는 이 사용자·SYSTEM·관리자만 읽을 수 있게 권한을 좁힌다. |
| 아무 PC나 접속 | 방화벽은 **같은 서브넷만** 허용한다(`-RemoteAddress`로 바꿀 수 있음, 관리자 권한 필요). |

관리 명령(서버를 켠 채로 써도 바로 적용):

| 할 일 | 명령 (`central` 폴더에서) |
|---|---|
| 등록된 PC 목록 | `npm run admin -- installs` |
| PC 차단(토큰 무효) | `npm run admin -- revoke <설치 ID>` |
| 가입키가 샜을 때 | `npm run admin -- rotate enroll` → `npm run release -- kit <폴더>`로 새 설치 묶음. 이미 등록된 PC는 그대로 |
| 검토자 키가 샜을 때 | `npm run admin -- rotate reviewer` → 검토자 PC에서 `/중앙 검토자 <새 키>` |
| 인증서 지문 보기 | `npm run admin -- fingerprint` |

인터넷에는 열지 않는다. 밖에서 접속해야 하면 VPN(Tailscale 등)으로 같은 네트워크로 묶는다.

## 7. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| `중앙 서버에 연결하지 못했습니다` | 서버 창이 켜져 있는지, 주소·포트가 맞는지, `host`가 `0.0.0.0`인지, 방화벽이 열려 있는지 |
| `포트 …를 이미 쓰고 있습니다` | `settings.json`의 `port`를 바꾼 뒤 스크립트를 관리자 권한으로 다시 실행 |
| `가입키가 맞지 않습니다` | 서버 창이나 `config.json`의 `enrollKey`를 다시 확인 |
| `등록되지 않은 설치입니다` | 서버의 `data` 폴더가 바뀌었다. `/중앙 연결`로 다시 연결 |
| `/중앙`에 "막힌 묶음"이 있음 | 그 PC의 `%LOCALAPPDATA%\MyCivil3DMcp\data\outbox\blocked`에 사유가 있다. 개인 정보가 섞여 보내지 않은 것이다. |
