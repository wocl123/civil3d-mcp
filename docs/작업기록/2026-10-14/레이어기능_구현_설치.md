# 레이어 기능 구현 및 로컬 설치 (2026-10-14)

## 구현

- `plan_layer_create`: 여러 레이어 이름과 ACI 색상(1~255, 기본 7)으로 생성 계획을 만든다.
- `plan_layer_delete`: 사용하지 않는 레이어 삭제 계획과 삭제 불가 사유를 보여 준다.
- 현재 레이어, 0, Defpoints, 외부참조 및 객체·블록·배치·도면 설정에서 참조하는 레이어는 삭제하지 않는다.
- 계획은 기존 적용·취소·되돌리기·확정 흐름을 사용한다. 레이어 변경도 리비전과 Undo 기록에 포함한다.
- 사용자 동의, 도면 식별·리비전 검사, 삭제 가능 여부 재검사, 응답 유실 시 결과 조회를 적용한다.
- 레이어 안의 객체를 삭제하거나 다른 레이어로 이동하는 기능은 포함하지 않는다.

## 검증

- 플러그인 Release 빌드: 경고·오류 0개.
- 서버 빌드와 lint, 레이어 시나리오, 기존 삭제·선형 편집·안전성·MCP 도구 회귀 검증 통과.
- 패키징 전체 검증: 설계 계산 35건, 안전성 17건, 자동 재등록 등 수신·관리 흐름 검증 통과.
- 서명된 ZIP·EXE의 설치·업데이트·복구·제거·변조 거절 검증 통과.
- 실제 Civil 3D 2025에서 레이어 생성·삭제·되돌리기 실행은 아직 확인하지 않았다.
