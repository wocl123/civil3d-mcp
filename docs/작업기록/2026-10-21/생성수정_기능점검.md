# 생성·수정 기능 점검 및 확장

기준: 2026-10-21 개발 소스, Civil 3D 2025 / .NET 8, 버전 0.1.16 유지.
아래의 지원은 등록된 MCP 도구부터 플러그인 적용 코드까지 연결된 범위다.
실제 팔레트의 모든 사용 조합을 사람이 검증했다는 뜻은 아니다.
내부배포 여부는 작업 종료 보고와 설치 메타데이터로 구분한다. 공개 Release와 버전 변경은 수행하지 않는다.

## 현재 구현 범위

| 대상 | 생성 | 수정 | 제한 및 검증 근거 |
| --- | --- | --- | --- |
| 평면선형 | 2D 폴리선 기반 직선·원곡선·완화곡선 배치 | 이름·설명·스타일·레이어·라벨 세트·설계속도, 기준 검토에서 계산한 단독 원곡선 반지름 | 임의 IP 이동·요소 추가/삭제·SCS 전체 재구성 도구는 없음. 수치 수정은 DesignChanges가 허용한 종류만 적용 |
| 종단 | PVI 기반 설계종단(FG), 지표면 종단(EG) | 속성, FG 전체 PVI/대칭 포물선 교체, 기준 수정안의 PVI 표고·곡선 길이 | EG에 설계 PVI 입력 금지. 전체 형상 교체는 기존 PVI·곡선을 모두 대체 |
| TIN 지표면 | 빈 지표면, 명시 XYZ 점·표준 브레이크라인·외곽 경계 | 속성·정점 추가/삭제·브레이크라인/경계 추가·표고 증감·재작성 | TIN 형상 편집만 지원. 경계/정의 항목 개별 제거·삼각망 선 교환 등은 없음 |
| 종단뷰 | **이번 추가:** 선형 기반 단일 격자, 명시 WCS 삽입 위치 | **이번 추가:** 이름·설명·스타일·레이어·위치 | 종단 데이터와 별도. 분할/적층·측점/표고 범위·밴드 편집은 없음 |
| 중력식 관망 | 빈 관망과 기준 선형/지표면·부품 목록 지정, 카탈로그 규격의 실제 관·구조물 생성 | 관망 속성, 직선관 중심선 좌표·정확한 규격 교체·연결/해제, 구조물 위치·회전·상단/바닥 표고·규격 | 압력관망·곡선관 끝점 편집 미지원. 설계 규칙 자동 적용 없음. 검사하는 같은 관망/라벨 중 잠금·참조 객체가 있으면 차단 |
| COGO 측량점 | 명시 점번호와 XYZ 좌표, 원시 설명·점/라벨 스타일 | 위치·일괄 이동·표고·원시 설명·스타일·레이어·단일 점번호 변경 | 번호 중복 덮어쓰기 없음. 잠금·측량 DB·프로젝트·이동 불가 점 거부. 설명키 자동 적용 없음 |
| TIN 토공량 지표면 | 서로 다른 기준·비교 TIN과 절성토 계수 | 이름·설명·스타일·레이어·계수·재작성 | 원본 지표면과 기준/비교 참조는 변경하지 않음. 실제 공통 삼각망이 없으면 적용 전체 롤백 |
| 기본 도형 | LINE·경량 폴리선·직사각형·원·호 | **이번 추가:** 이동·명시 기준점의 균일 축척/Z축 회전·원/호 반지름·레이어·ACI 색상 | 기존 핸들 유지. 꼭짓점·bulge 개별 편집, 비균일 축척, 블록/Civil 객체 편집은 없음 |
| 문자 | TEXT·MTEXT | 내용·찾아 바꾸기·높이·회전·스타일·레이어·색상·위치/이동 | 블록 속성·Civil 라벨 제외. MTEXT 전체 내용 교체 시 인라인 서식 소실 가능 |
| 치수 | 정렬·회전·반지름·지름·각도·좌표 치수 | 문자·문자 위치·스타일·레이어·회전 치수 각도 | 비연관 치수. 문자 덮어쓰기는 원본 형상을 바꾸지 않음 |
| 일반점 | 명시 XYZ 또는 선/폴리선 꼭짓점 | 절대 위치·상대 이동·레이어 | AutoCAD POINT이며 측량 COGO 점이 아님 |
| 레이어 | 이름·색상·잠금/동결/켜짐 상태 | 색상·잠금/해제·동결/해동·켜기/끄기 | 기존 레이어 이름 변경 도구 없음. 현재/외부참조 레이어 보호 |

표시·선택·숨김/격리·객체 뷰어·줌은 별도로 지원하지만 설계 형상 생성/수정으로 세지 않는다.
관망·지표면 일괄 삭제, 선형/종단/코리더 삭제도 생성/수정 지원과 구별한다.

## 이번 코드 연결

- MCP: `plan_geometry_edit`, `plan_pipe_network_create/edit`, `list_profile_views`, `plan_profile_view_create/edit`.
- C#: `GeometryEditing.cs`, `NetworkProperties.cs`, `ProfileViewChanges.cs`.
- `CivilPlans`에서 미리 보기·정규화·상태 지문 재검증·트랜잭션 적용을 수행한다.
- 기존 `apply_drawing_change`만 쓰기 권한을 갖는다. 새 계획 도구도 계획 표시 후 동의가 있어야 적용된다.
- 도형은 정확한 좌표·반지름·bulge·폭·상태를 계획에 기록해 원본 변경을 재검사한다.
- 새 관망/종단뷰 편집은 참조 객체와 잠금/외부참조 레이어를 차단한다.
- 팔레트 지침에 일반점/COGO, 종단/종단뷰, 빈 관망/배관 설계를 구별하도록 추가했다.

## 보완할 부분과 후속 개발 입력

우선순위 1의 세 항목은 후속 보완을 구현했다. 나머지는 현재 팔레트에 구현하지 않은 기능이며 API 존재와 사용 가능 상태를 혼동하지 않는다.
우선순위는 기존 객체 조회·선택·승인 구조 재사용 정도와 필요한 설계 입력의 범위를 바탕으로 한 개발 판단이다.

| 우선 | 기능 | 구현할 생성·수정 | 먼저 확정/조회할 정보 |
| --- | --- | --- | --- |
| 보완 구현 | COGO 측량점 | 생성·좌표·표고·설명·스타일·점번호 수정 연결 | 번호 충돌 차단, 점 그룹 표시 재지정 유지, 측량 DB 점 편집 차단 |
| 보완 구현 | 관·구조물 실제 설계 | 카탈로그 조회·생성·연결·표고·정확한 규격 교체 연결 | 카탈로그에서 선택, 중심선 표고와 관저 구분, 자동 설계 규칙 미적용 |
| 보완 구현 | 토공량 지표면 | TIN Volume 생성·속성/계수 수정·결과 조회 연결 | 기준/비교 구분, 공통 삼각망 적용 검사, 도면 좌표 단위의 세제곱 |
| 2 | 형상선(Feature Line) | 기존 선/폴리선에서 생성, PI/표고점 편집 | Site 선택, 상호 교차 및 표고 갱신 영향 |
| 2 | 횡단 | SampleLineGroup/SampleLine 생성, 샘플 소스·폭·측점 수정, 횡단뷰 | 선형·간격/측점 목록·좌우 폭·지표면/코리더 소스·스타일 |
| 2 | 코리더 | 기준선/영역 생성·수정, 타깃·빈도 설정·재작성 | 선형/종단 또는 형상선, Assembly·Subassembly, 영역·타깃 매핑 |
| 3 | 압력관망 | 버전별 공개 API에 맞춘 부품 생성·편집 | 카탈로그·부품 런·굴곡/피팅 연결 규칙, 2025 API 제약 확인 |
| 3 | 필지·정지·라벨·테이블 | 객체별 생성·편집 경로 조사 후 전용 도구 | Site/종속성, 공개 .NET API 미지원 시 COM 필요 여부, 도면 영향 |

추가 보완 완료: Civil 생성·수정 계획에 WCS·Civil 단위·삽입 단위·좌표계를 표시하고, 스타일/부품 카탈로그 조회 도구를 제공한다.
기존 지표면·종단의 모든 속성/형상 조합에 대한 잠금·참조·저장 후 재열기 검사를 확대해야 한다.
수치 설계 수정은 평면 원곡선 반지름, PVI 표고, 종단곡선 길이 세 종류만 적용 가능하며,
타입 선언에 존재하는 profileTangent/alignmentSpiral 등이 곧 적용 지원을 뜻하지 않는다.

## 검증 및 수동 확인

`tests/CivilCrud.Native/CreationExtensions.cs`는 실제 Autodesk 엔진에서 다음을 검사한다.

- 종단뷰 실제 생성·이동/속성 수정·조회·중복/빈 수정 거부.
- 빈 중력식 관망 생성·기준 선형 지정·이름 변경·잘못된 기준 객체 거부.
- 도형 변환 순서·반지름·핸들 유지·미리 보기 비변경·변경된 원본 계획 차단.
- 새 생성의 트랜잭션 롤백/Undo, 도형 수정 Undo, 잠금 레이어 차단.
- 별도 관망 시험 도면에서 기존 관·구조물이 있는 관망의 속성 수정 후 소속 부품 유지.

후속 검사는 `EngineeringTests.cs`, `NetworkPartTests.cs`에 있다. COGO와 토공량의 생성·편집·롤백·Undo,
실제 관·구조물 생성·규격 교체·연결/해제·표고 수정과 저장 후 새 프로세스에서 재열기까지 검사한다.
실제 측량 DB/프로젝트 점, 모든 부품 카탈로그/구조물 타입, 대형 도면과 곡선관 전체 조합의 수동 확인은 별도다.

MCP 검사는 새 계획들의 저장·동의 전 쓰기 금지·적용·중복/오래된 계획 거부를 검사한다.
공식 자동 검증 결과는 `.package-cache/internal-test/report.json`을 기준으로 확인한다.
자동 통과와 별개로 실제 팔레트 수동 확인은 대기이며, `-ConfirmManualPass`를 임의 실행하지 않는다.

수동 확인 시 개발 DLL 중복 로드를 피하고 내부배포 절차로 설치한 뒤 다음을 확인한다.

1. 선택한 원을 명시한 반지름으로 수정하고 이동·Undo 확인.
2. 기존 선형의 원하는 WCS 위치에 종단뷰를 만들고 이동·스타일 변경·Undo 확인.
3. 빈 중력식 관망을 만들고 기준 선형/지표면과 이름·설명을 변경·Undo 확인.
4. 진행 전 도면이 바뀌지 않고 취소 시 그대로인지, 잠긴 레이어에서 차단되는지 확인.
