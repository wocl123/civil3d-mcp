# Civil 3D 기본 기능 확장

후속 구현 범위와 제한은 [2026-10-22 기능확장 결과](../2026-10-22/기능확장_결과.md)를 따른다. 아래 내용은 착수 시점의 기록이다.

사용자 요청: 기존 감사에서 확인한 누락 기능과 세부 편집 기능을 모두 추가한다.
Git 커밋·푸시는 별도 사용자 승인 전까지 하지 않는다. 버전은 유지한다.

## 완료 기준

도구 이름만 등록하거나 네이티브 대화상자를 여는 것을 자동 생성·수정 완료로 계산하지 않는다.
각 기능은 입력 검증, 변경 계획, 적용 직전 상태 재검증, 트랜잭션·Undo, 실제 엔진 검증을 갖춘다.
Civil 3D 2025에 없는 API는 지원한다고 표시하지 않는다.
전체 자동 검사와 실제 팔레트 수동 확인을 분리한다.

## 구현 대상

- 일반 작도: 복사, 대칭, 오프셋, 배열, 자르기, 연장, 모깎기, 모따기, 결합, 끊기, 폴리선 정점, 3D 폴리선.
- 블록·속성, 해치, 다중 지시선, 표.
- 형상선 생성·표고·PI·표고점 편집.
- 횡단추출선 그룹·추출선·소스·횡단뷰.
- 표준횡단·서브어셈블리, 코리더 기준선·구간·타깃·빈도·지표면.
- 부지·필지·정지, 압력관망, 측량 DB, 데이터 바로가기, 시트·출력.
- Civil 라벨·스타일, 자료 입출력.
- 선형 오프셋·확폭·교차로·PI·측점 방정식·편경사 편집.
- 종단 개별 PVI, 종단뷰 범위·밴드·분할.
- 지표면 정의 입력·붙여넣기·단순화·경계·삼각망·표고·경사.
- 점 그룹·설명 키·사용자 속성·입출력·COGO 삭제.
- 중력식 곡선관·일괄배치·규칙·경사·토피.
- 레이어 이름·선종류·선가중치·투명도·출력.
