# 0.1.16 배포 (2026-10-16)

사용자의 `이제 배포` 요청에 따라 기존 버전업 보류를 해제하고 0.1.16을 배포했다.

## 결과

- 공개 릴리스: https://github.com/wocl123/civil3d-mcp/releases/tag/v0.1.16
- 최신 설치 안내: https://github.com/wocl123/civil3d-mcp/releases/latest
- 설치 파일: https://github.com/wocl123/civil3d-mcp/releases/download/v0.1.16/MyCivil3DMcp-0.1.16-win-x64.exe
- EXE 크기: 111,177,155바이트 (약 106 MiB).
- EXE, RSA 서명, SHA-256, 서명된 latest.json을 게시했다. 공개 다운로드와 로컬 EXE 바이트 일치를 확인했다.
- 릴리스는 공개 및 immutable 상태이며 latest로 게시했다. 기존 배포 버전은 덮어쓰지 않았다.
- 현재 PC도 0.1.15에서 0.1.16으로 설치 완료. 기존 설치를 D드라이브에 백업했다.
- 설치된 DLL은 이번 빌드와 해시가 같고, 번들 manifest/서명 검사를 통과했다.
- 사용자 데이터 파일 77개를 설치 전후 비교하여 모두 동일함을 확인했다.
- 재부팅하거나 실행 중 사용자 CAD를 종료하지 않았다. 소스 커밋·푸시는 하지 않았다.

## 포함 변경

- [팔레트 속도 개선](팔레트_속도개선.md): HTTP MCP 서버 재사용, 문맥 일괄 조회, PATH 캐시, 단일 계획 적용 동의 시 AI 호출 생략. AI CLI 자체는 질문마다 실행한다.
- [수정요청 6건 처리](수정요청_처리.md): 일반 치수/POINT CRUD, 보수적 정리 검사와 후보 삭제, 객체뷰어 선택 전달, 지표면 일괄 삭제 및 실패 반복 호출 방지, 취소 집계, 스타일 변경 후 분리 지침.
- 앞선 로컬 0.1.9~0.1.15의 레이어/지표면/선형/종단 CRUD 및 쓰기 권한 보완, AI 설치·로그인 창, 사용량 표시, 관리자 CLI 개선도 포함한다.

## 검증

`scripts/deploy.ps1 -Version 0.1.16`으로 새 버전을 빌드하고 패키지 검사를 실행했다.
서버 기능·안전성·MCP 계약·설계·삭제·수정·레이어·관리자·재연결·서비스 수명·기억·지식·사용량·AI 오류·CLI 설치 흐름·수신/업데이트 채널 회귀가 통과했다.
RuntimePaths, QuotaFooter, ProviderSetup, ProfileLayout C# 검사와 실제 Civil 엔진의 임시 도면/저장 DWG 검사도 통과했다.

배포본 자체의 동봉 Node/운영 의존성/stdio 및 HTTP MCP 검사, 설치·재설치·백업·복구·변조/경로 탈출 거부·제거·사용자 데이터 보존, 실제 EXE 설치·서명 업데이트·변조 EXE 거부 검사도 통과했다.

마지막 EXE 업데이트 시험에서는 D드라이브 작업 공간 아래 긴 임시 경로로 인해 SDK 예제 파일의 전체 경로가 260자가 되어 MoveFile 오류가 났다. 시험 임시 폴더 접두사를 줄여 전체 경로를 줄인 후 같은 EXE로 재검증하여 통과했다. 실패 로그도 보존하도록 시험 스크립트를 보완했다. 이 수정은 시험 코드이며 EXE 내용은 바꾸지 않았다.

이후 `server/scripts/github-publish.mjs`로 실제 EXE의 배포 저장소/수신 설정/서명 메타데이터를 검증하고 `scripts/deploy.ps1 -Version 0.1.16 -SkipBuild`로 검증된 같은 산출물을 게시했다.

현재 PC 설치 후 `.package-cache/check-installed-tools.mjs`로 새 치수·점·정리 도구, 지표면 목록/이름 조건 삭제 스키마, 레이어 상태, 객체뷰어 동작 옵션 및 단일 쓰기 도구 구성을 확인했다.
