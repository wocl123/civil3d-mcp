# Civil 3D 생성·수정 기능 확장

후속 누락 기능 구현은 [2차 확장 결과](추가확장_2차.md)를 따른다. 아래는 1차 확장 기록이다.

버전은 0.1.16을 유지한다. Git 커밋·푸시와 공개 Release는 하지 않는다.
이 문서는 구현 범위이며, 전체 자동 검사 결과는 `.package-cache/internal-test/report.json`, 설치 결과는 `.package-cache/internal-deploy/`의 기록으로 확인한다. 실제 팔레트 수동 확인은 별도이며 아직 완료 처리하지 않는다.

## 직접 API로 생성·수정하는 기능

MCP 도구 26개를 추가했다. 변경 계획에서 대상을 특정하고, 적용 직전 도면·객체 상태와 잠금·참조 조건을 다시 확인한다. 입력 파일은 계획 시점과 적용 시점의 해시를 비교한다.

## Civil 3D 대화형 기본 명령 연결

설치된 CUI에서 확인한 허용 명령을 조회하고 실행하는 도구를 추가했다. 정지·토공, 필지, 측량, 데이터 바로가기, 교차로·편경사·확폭, 표준횡단·서브어셈블리, 밴드·분할 뷰, 재료 수량·토적곡선, 뷰 프레임·시트, 가져오기·내보내기, 관망 배치와 출력 작업을 포함한다.

이 경로는 Civil 3D의 기본 명령을 시작하며 이후 점 선택이나 대화상자 입력이 필요하다. 명령 실행 접수를 설계·파일 생성 완료로 보고하지 않는다. 실제 UI 흐름의 수동 확인도 남아 있다.

## 검증 및 남은 제한

- 개별 서버 회귀 검사와 Autodesk 엔진 생성·수정·저장 후 재열기 검사를 통과했다. 전체 내부 검사 및 설치 상태는 위 결과 기록을 따른다.
- 실제 엔진에서 형상선, 횡단, 코리더 구간, 압력관과 중력 곡선관, LandXML, 점 사용자 속성, 레이블, 일괄 변경의 Undo·실패 시 롤백 등을 검사한다. 모든 카탈로그·도면 조합과 각 선택 옵션의 검증을 의미하지 않는다.
- 필렛·모따기는 공통 끝점에서 만나는 XY 선 두 개, 결합은 순서대로 연결된 동일 평면·속성의 선을 대상으로 한다. 압력 곡선관은 세 점의 Z가 같은 경우만 지원한다.
- 새 표준횡단은 빈 컨테이너다. 완성된 도로 단면은 실제 서브어셈블리의 부착·설정이 필요하다.
- CSV는 `number,x,y,z,description` 헤더와 최대 1,000점을 지원한다. 배치에서 앞 단계가 새로 만든 객체를 후속 단계 대상으로 지정하지 않는다.
- 규칙 적용·피팅·부속·포트 연결 등은 구현했으나 모든 실제 카탈로그 조합을 검사하지 않았다. 수동 검증 때 우선 확인한다.

## 응답 시간

기존의 AI 없는 직접 계획·조회 경로를 유지하고 여러 변경을 한 배치로 묶는 경로를 추가했다. 스타일 조회는 페이지에 포함된 스타일의 구성요소만 읽는다. 서버 테스트의 빠른 계획 경로 측정값은 전체 AI 응답 시간이나 실제 도면 실행 시간과 구분한다.

## 내부배포 후 수동 확인

일반 Civil 3D 실행으로 설치 팔레트를 연다. 형상선 표고 수정, 횡단 뷰 생성, 압력관 생성·연결, 점 CSV·사용자 속성, 레이블 수정, 기본 대화형 명령, 배치 적용·Undo를 확인한다. 개발 DLL의 NETLOAD는 요구하지 않는다. 현재 수정본의 실제 기능 확인을 명시적으로 받은 후에만 수동 통과를 기록한다.
