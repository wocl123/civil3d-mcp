## 연속 작업의 검증 방식

1. 모든 단계의 입력과 앞 단계 참조를 검사한다.
2. 같은 실행 코드를 임시 트랜잭션에서 순서대로 실행하고 항상 롤백한다. 임시 핸들은 저장 계획에 포함하지 않는다.
3. 계획은 도면 ID·리비전과 명시한 단계/설계값에 연결한다.
4. 적용 직전 재검증하고 실제 핸들을 다시 연결한다. 전체 성공 시 커밋하며 중간 실패는 전체 롤백한다.
5. 기존 일괄 변경과 마찬가지로 단일 Undo로 복원한다.

새 객체를 만들 때마다 AI에게 결과 핸들을 다시 넘기는 왕복을 줄이는 경로다. 미리 보기에서 실제 생성 순서를 롤백 검증하므로 순수 조회보다 엔진 계산 비용이 들 수 있다.

## 통합 검사

실제 Autodesk 엔진 검사에 연속 생성의 미리 보기 결정성·리비전 유지·전체 롤백·Undo·잘못된 후속 입력, 형상선/횡단/관로 런 삭제, 선형 요소 편집, 분석 구간·물 흐름 경로, 속성 세트 부착/값/분리, 실제 Civil 라벨, 수량표 원본 변경 후 갱신 및 저장 후 재열기를 추가한다. 결과는 위 자동 검사 기록을 따른다. 모든 도면·스타일·카탈로그 조합 검증을 의미하지 않는다.

현재 팔레트 수동 검증 전에는 내부 테스트 전체 완료로 처리하지 않는다. 내부배포한 수정본은 일반 Civil 3D 실행으로 사용하고 NETLOAD를 요구하지 않는다.

## 계속 구별할 범위

필지·정지·편경사 자동 설계와 전체 선형 구속조건 편집, 자동 유역 계산, 속성 세트 정의 전체 편집은 이번 직접 API 코드에 포함하지 않는다. 앞서 연결한 Civil 3D 기본 대화형 경로와 혼동하지 않는다. 기본 명령 접수를 설계 완료로 보고하지 않는다.
