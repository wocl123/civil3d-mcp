## 새 생성·수정·삭제 기능

| 대상 | 생성 | 수정 | 삭제 |
| --- | --- | --- | --- |
| 지표면 | TIN: XYZ 점, 표준 브레이크라인, 외곽 경계 또는 빈 지표면 | 이름·설명·스타일·레이어, 점 추가·정점 삭제, 브레이크라인·경계 추가, 전체 표고 증감, 재작성 | 원본 참조가 없는 로컬 지표면. 연결된 설계 객체는 자동으로 삭제하지 않음 |
| 종단 | 설계 PVI 및 내부 PVI 대칭 포물선, 지표면에서 EG 종단 추출 | 속성 변경, 설계종단 PVI 전체 교체. 기존 개별 PVI 표고·곡선 길이 수정도 유지 | 기존 선형·종단 삭제 도구 유지 |
| 선형 | 기존 폴리라인 기반 생성 유지 | 기존 속성·설계속도·원곡선 반지름 수정 유지 | 기존 연관 객체 미리보기·삭제 유지 |
| 레이어 | 기존 상태 포함 생성 유지 | 기존 색상·잠금·동결·켜짐 변경 유지 | 기존 미사용/객체 포함 삭제 유지 |

종단 생성은 종단 객체를 만드는 기능이며 종단 뷰 그리드 배치는 포함하지 않는다.
지표면 형상 편집은 TIN 대상이며 Grid/토공량 지표면을 TIN처럼 변경하지 않는다.
지형 표고·설계 PVI를 AI가 임의로 만들어 넣지 않도록 도구 설명과 팔레트 지침을 함께 보강했다.

## 적용·복구 보호

- 새 도구 8개: `list_surfaces`, `get_surface`, `plan_surface_create/edit/delete`,
  `plan_profile_create/edit`, `plan_drawing_display`.
- 새 브리지: `surface.list/get`, `drawing.civil_preview/apply`.
- 미리 보기는 읽기 전용이다. 플러그인이 대상 이름을 핸들로 정규화하고 상태 지문을 만든다.
- 기존 도면 ID·리비전·계획 수명·동의한 수정안 ID·중복 적용 차단을 그대로 사용한다.
- 적용 직전 재검증하고 단일 트랜잭션에서 처리한다. 오류 시 전체 롤백한다.
- 지표면 삭제는 persistent reactor 외에 EG 종단, 토공량 지표면, 지표면 붙여넣기,
  코리더 타깃/소유 지표면, 횡단 추출 소스를 확인한다. 예상하지 않은 종속 삭제도 감시한다.
- 참조 Civil 객체 수정·삭제, 없는 스타일/레이어, 이름 중복, 범위 밖/역순 PVI와 곡선 겹침을 거절한다.
- 객체뷰어는 비동기 예약 실행해 사용자가 창을 열어 둬도 AI 적용 요청이 시간 초과되지 않게 한다.
  성공 메시지는 창이 렌더링됐다는 뜻이 아니라 열기 요청을 전달했다는 뜻이다.
- 객체 선택·뷰어 등 도면 객체를 바꾸지 않는 작업은 `undoAvailable=false`로 Undo 버튼을 숨긴다.
  객체 분리·숨김은 분리 해제 도구로도 복원할 수 있다.
- 실제 적용 래퍼의 UNDO End 명령이 PickFirst 선택을 지우는 문제를 확인했다.
  선택·뷰어는 형상 편집 그룹을 만들지 않고 이전 편집의 Undo 감시도 유지하도록 수정했다.
