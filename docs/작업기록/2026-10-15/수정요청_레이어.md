# 레이어 수정 요청 처리 (2026-10-15)

대상: 관리자 보관함의 `수정요청-2026-10-14.md`, 코드 수정 사례 1~3.

| 사례 | 원인 | 수정 | 회귀 시험 |
| --- | --- | --- | --- |
| 1. 잠긴 레이어 생성 | 생성 입력에 색상과 이름만 있었다. | 생성 시 locked·frozen·off를 받는다. 기본값은 false다. | 잠금·동결·꺼짐 동시 생성, 기본 상태, 동의 전 무변경 |
| 2. 레이어 상태 변경 | 기존 레이어의 속성 변경 도구가 없었다. | plan_layer_edit로 잠금/해제, 동결/해동, 켜짐/꺼짐, 색상을 계획·적용한다. | false와 생략 구분, 색상 보존, Undo, 현재 레이어 동결·외부참조 거절 |
| 3. 사용 중인 레이어 삭제 | 객체가 있으면 항상 거절했다. | 객체 수·종류·관련 영향을 알리고 동의 후 객체 포함 계획을 만든다. | 관망 및 다른 레이어의 관·구조물·라벨 삭제/복원, 중복 제거, 변경된 삭제 목록 거절 |

## 변경 범위

- 플러그인: `DrawingLayers.cs`, `LayerState.cs`, `LayerObjects.cs`.
- 서버: 레이어 MCP 도구·요청 타입, 적용 결과, 카드 종류, 진행 문구.
- 지시문·문서: 팔레트 레이어 작업 지침과 README.
- 시험: `layer-state-scenario.mjs`, 기존 레이어/도구 목록 시나리오, 패키징 시험 목록.
- 버전: 0.1.10. 커밋·태그·푸시·GitHub 공개 배포는 하지 않는다.

## 객체 포함 삭제

1. 처음에는 deleteObjects=false로 객체와 영향을 확인한다. 사용 중이면 객체도 지울지 묻는다.
2. 동의 후 deleteObjects=true로 새 계획을 만든다. 새 계획의 진행 버튼이나 후속 동의로만 적용한다.
3. 모형·배치·블록 정의와 관망 종속 객체를 읽는다. 블록 정의 변경은 모든 배치에 영향을 준다고 알린다.
4. 관망을 삭제하면 소속 관·구조물과 종속 라벨을 포함하고, 다른 레이어의 객체도 목록·영향에 포함한다.
5. 적용 직전에 레이어 핸들·도면 리비전·실제 객체 목록을 다시 비교한다.
6. 남은 설정 참조 또는 계획에 없던 종속 삭제가 발견되면 전체 트랜잭션을 취소한다.

0·Defpoints·현재 레이어·외부참조는 삭제할 수 없다. 참조 Civil 객체 및 아직 종속 삭제를 다루지 않는
Civil 타입은 거절하며, 선형·종단·코리더는 기존 전용 삭제 도구를 사용한다. 한 요청의 삭제 객체는 1000개까지다.
색상을 생략한 상태 변경은 기존 True Color도 유지한다.

## 확인 결과

- C# Release 빌드: 경고 0, 오류 0.
- TypeScript 빌드·lint 통과.
- 기존 레이어 및 새 상태·객체 포함 삭제 시나리오 통과.
- 설계 계산 35건, 안전성 17건, MCP 도구·기존 삭제·선형 편집·관리자 메뉴 검증 통과.
- 실제 Civil 3D에서 실행한 결과는 아직 확인하지 않았다. 테스트 브리지를 이용한 회귀 검증이다.
- 0.1.10 서명 ZIP·EXE 생성 및 패키지·EXE 설치·복구·제거·변조 거절 검증이 모두 통과했다.
- 최초 설치 시도는 실행 중인 CAD 검사에서 중단됐고, 사용자가 CAD를 종료한 뒤 현재 PC에 0.1.10 설치를 완료했다.
- 플러그인 빌드 일치, 설치 파일 목록·해시·서명과 사용자 데이터 50개 파일의 내용 보존을 확인했다.
- 실제 설치된 Node/MCP 서버를 실행해 생성·상태 변경·삭제 도구와 잠금·동결·객체 포함 삭제 입력이 노출됨을 확인했다.
- 이전 설치 백업: `.package-cache/installed-backups/0.1.9-dcc4a7214f2f48989ef64b270bcf5ca4/`.
- 설치 결과: `.package-cache/install-0.1.10-result.json`. 실제 CAD에서의 도면 편집 검증은 사용자가 이어서 진행한다.
- 설치 파일: `dist/MyCivil3DMcp-0.1.10-win-x64.exe`. 관리자 사례는 실제 사용 확인 전까지 완료 처리하지 않는다.
