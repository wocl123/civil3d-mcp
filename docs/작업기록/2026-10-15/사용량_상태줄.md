# AI별 사용량 상태줄 (2026-10-15)

사용자 참고 이미지처럼 하단을 `아이콘 / 막대 / 단기 사용률·재설정 남은 시간 / 주간 사용률·남은 시간`으로 변경했다.
숫자는 남은 비율이 아니라 사용한 비율이다. 예: `7% 4h 7m · 60% 1d 10h`.

## 변경

- `QuotaStrip`: Claude·Codex 아이콘, 사용률 막대, 두 한도 구간. 좁은 팔레트에서는 줄 바꿈한다.
- `QuotaDisplay`, `QuotaWindowDisplay`: 사용률과 카운트다운 변환. 누락·실패·만료된 수치를 0%로 표시하지 않는다.
- `ChatPanel`: AI별 조회 결과·토큰 값을 구분해 전환 시 섞이지 않게 했다. 토큰 상세는 툴팁에 둔다.
- 보이는 팔레트는 1분마다 한도와 남은 시간을 갱신한다. 같은 AI의 중복 조회를 막는다.
- 사용 제한은 수치가 있더라도 표시한다. 기존 버전·새로고침·관리자 알림은 유지한다.
- Claude 직접 조회는 기존 Agent SDK 도우미를 배포본에 포함한다. SDK 조회 실패 시 최근 상태줄 기록으로 대체한다.
- 사용자 CLI 로그인·설정·상태줄 설정은 변경하지 않는다. Codex는 기존 app-server 조회를 사용한다.
- Simple Icons v14.0.0의 Claude·OpenAI SVG를 내장하고 설치본에 CC0 라이선스를 포함한다.

## 검증

- WPF 미리보기와 회귀 테스트: 사용한 비율, 남은 시간, 만료·누락·실패, AI 전환, 제한 상태 표시 통과.
- 어두운·밝은 테마와 좁은 폭을 실제 WPF로 렌더링해 확인했다.
- 산출 이미지: `test-results/quota-footer/claude.png`, `codex.png`, `claude-light.png`, `codex-light.png`, `codex-narrow.png`.
- 플러그인 Release 빌드: 경고·오류 0. TypeScript 사용량 테스트와 lint 통과.
- 실제 Claude·Codex 계정에서 모두 5시간·7일 사용률과 재설정 시각을 조회했다. AI 질문은 보내지 않았다.
- 패키징 시 Claude SDK 의존성이 동봉 런타임에서 로드되는지도 확인했다.
- 전체 회귀 검사, 서명·변조 거부, ZIP 설치·업데이트·복구, EXE 설치·재설치·제거 검사 통과.
- 로컬 설치 후 동봉 Node로 Claude·Codex를 각각 조회해 모두 `available`, 한도 구간 2개를 확인했다.

## 로컬 설치

서명된 0.1.11 EXE를 생성하고 로컬 설치를 완료했다. 설치본 서명과 플러그인 빌드 해시가 일치한다.
기존 사용자 파일 50개의 설치 전후 해시가 모두 같았다.
이전 0.1.10 설치본은 `.package-cache/installed-backups/0.1.10-b6dba4a6e62b494aad98f7d2db3c2196`에 보관했다.
설치 결과는 `.package-cache/install-0.1.11-result.json`에 기록했다.
공개 배포·커밋·태그·푸시는 하지 않았다. CAD를 다시 실행하면 적용된다.
실제 CAD 팔레트의 화면은 아직 확인하지 않았으며, WPF 렌더링과 계정 조회를 각각 검증했다.
