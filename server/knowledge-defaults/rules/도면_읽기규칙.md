# 도면 읽기 규칙

## 1. 지금 읽을 수 있는 범위
- 모형 공간(Model)만 읽는다. 배치(Layout), 뷰포트, 외부참조(Xref) 안의 객체는 읽지 못한다. 찾지 못했을 때는 "도면에 없다"가 아니라 "모형 공간에서 찾지 못했다"고 답한다.
- 문자(Text, MText)의 내용, 치수 값, 블록 이름과 속성은 아직 읽지 못한다. 이런 질문에는 읽지 못한다고 답하고 추측하지 않는다.
- 선형과 종단은 전용 도구로 상세하게 읽는다(선형·종단 규칙 파일 참고).
- 그 밖의 Civil 3D 객체(지표면, 횡단, 코리더, 관망 등)는 종류, 레이어, 범위만 읽는다. 표고, 체적 같은 속성은 아직 읽지 못한다.

## 2. 레이어 상태
| 상태 | 의미 | 답할 때 |
| --- | --- | --- |
| 꺼짐(Off) | 화면에 보이지 않지만 도면에는 있다 | 개수에 포함하고 "꺼진 레이어"라고 표시한다 |
| 동결(Frozen) | 보이지 않고 화면 재생성에서도 빠진다 | 현행 여부를 단정하지 않는다 |
| 잠금(Locked) | 보이지만 편집할 수 없다 | 내용 판단에는 영향이 없다 |
| 객체 0개 | 이름만 정의된 빈 레이어 | 따로 묶어 언급한다 |

- 레이어 "0"과 "Defpoints"는 AutoCAD 기본 레이어다. Defpoints에는 치수 정의점이 들어가며 출력되지 않는다.

## 3. 좌표와 단위
- 좌표는 도면 단위 그대로다. 좌표계 코드가 있으면 함께 밝히고, 없으면 "좌표계 미지정"이라고 쓴다.
- 범위(bounds)는 객체를 감싸는 상자일 뿐 실제 형상이 아니다. 범위로 길이나 면적을 계산하지 않는다.

## 4. 큰 도면
- 객체가 수천 개를 넘으면 레이어 목록의 종류별 개수로 먼저 답하고, 객체 목록은 레이어를 지정해 작은 단위로 본다.
- 개수를 묻는 질문은 레이어 목록의 합계로 답한다. 객체를 하나씩 세지 않는다.

## 5. 확인되면 기록
- 레이어의 실제 내용을 객체로 확인했거나 사용자가 알려 주면 도면별 지식에 기록한다.
