# 종단 해석 규칙

모든 값은 Civil 3D가 계산해 둔 값을 읽은 것이다. 같은 값을 다시 계산하지 않는다. 도구가 주지 않는 값을 계산했다면 "계산값"이라고 밝힌다. 경사는 모두 % 단위다.

## 1. 조회 순서
1. 어떤 종단이 있는지는 get_alignment 개요의 profiles로 본다.
2. 한 종단은 get_profile로 개요를 먼저 본다. 개요에는 종류, 원본 지표면, 최고점·최저점, 묶음별 항목 수, Civil 3D가 주지 못한 부분(unavailable)이 있고, 계획 종단이면 30개 이하인 종단곡선(curves)과 경사 구간(tangents)까지 있다.
3. 개요에 없는 묶음만 get_profile_section으로 읽는다. 특정 구간은 fromStation·toStation(원래 측점 숫자)으로 좁힌다.

| 질문 예 | 읽을 묶음 |
| --- | --- |
| 측점 ○○의 계획고·지반고 | elevations (stations에 그 측점) |
| 일정 간격 표고표 | elevations (interval, 범위) |
| 종단경사 목록, 최대·최소 경사 | tangents |
| 종단곡선 L, K, 볼록·오목, 정점 | curves |
| VIP 목록, 시거 | pvis |
| 최고점·최저점 | 개요(highest, lowest) |
| 종단도 | views |
| Civil 3D 검사 세트 위반 | design_checks |
| 법령 기준 만족 여부 | check_profile_criteria (설계기준 규칙) |

- 이름이 같은 종단이 여러 개면 핸들로 구분하고 소속 선형 이름을 함께 밝힌다.

## 2. 종단 종류
| 종류 | 용어 | 해석 |
| --- | --- | --- |
| EG | 지표면 종단(현황 지반선) | 지표면에서 뽑은 선. settings.dataSource가 원본 지표면 이름이다. 지표면이 바뀌면 값도 바뀐다 |
| FG | 계획 종단(설계선) | 사람이 VIP로 설계한 선 |
| Superimposed | 중첩 종단 | 다른 선형의 종단을 이 선형에 투영한 선 |
| File | 파일 종단 | 외부 파일에서 가져온 선 |
| CorridorFeature | 코리더 피처 종단 | 코리더 피처 라인에서 나온 선 |
| OffsetProfile | 오프셋 종단 | 기준 종단(settings.parentProfile)에서 settings.offset만큼 떨어진 선 |
| CurbReturnProfile | 연석 회전부 종단 | 교차로 연석 회전부의 선 |

- "계획고"는 계획 종단(FG)의 표고, "지반고"는 지표면 종단(EG)의 표고다. 계획 종단이 여러 개면 이름으로 밝히고, 어느 것이 확정안인지는 사용자에게 묻는다(핵심 규칙 6). 확인되면 도면별 지식에 기록한다.
- settings.updateMode가 Dynamic이면 원본(지표면·기준 종단)이 바뀔 때 함께 바뀐다. Static이면 만든 시점 값에 고정되어 있어 원본과 다를 수 있다.
- 지표면 종단의 VIP와 직선 구간은 지표면 삼각망과 만나는 점이라 수가 많고 설계 의미가 없다. 지표면 종단은 개요의 최고점·최저점과 elevations로 답한다.

## 3. 측점
- 측점은 숫자(원래 측점)와 문자(…StationText)로 함께 온다. 사용자에게는 문자를 그대로 쓰고, 범위 지정과 거리 계산에는 원래 측점 숫자를 쓴다(선형 규칙 3).

## 4. 종단경사(tangents)
- 각 항목이 경사 구간 하나다: 시점·종점 측점과 표고, 길이, gradePercent.
- +는 측점이 커지는 방향으로 오르막, −는 내리막이다.
- 최대 종단경사는 gradePercent 절댓값이 가장 큰 구간이다. 최소 종단경사(배수 검토용)는 절댓값이 가장 작은 구간이다. 둘 다 측점 구간과 오르막·내리막을 함께 답한다.

## 5. 종단곡선(curves)
| 값 | 의미 |
| --- | --- |
| crestOrSag | Crest = 볼록(정점) 곡선, Sag = 오목(새그) 곡선 |
| curveType | Circular = 원곡선형, ParabolaSymmetric = 대칭 2차 포물선, ParabolaAsymmetric = 비대칭 포물선 |
| length | 곡선 길이 L. 비대칭이면 asymmetricLength1·2가 VIP 앞뒤 길이다 |
| pviStationText, pviElevation | 이 곡선의 VIP |
| gradeInPercent, gradeOutPercent | 들어오는·나가는 경사 |
| gradeChangePercent | 경사 차 A (Civil 3D 값) |
| k | K값 (Civil 3D 값) |
| radius | 곡선 반경 (원곡선형·대칭 포물선) |
| tangentOffsetAtPvi | VIP에서 곡선까지 수직 거리 |
| highLowPoint | 곡선 위의 정점(볼록) 또는 최저점(오목) 측점과 표고. 없으면 곡선 안에 정점·최저점이 없다 |
| minimumKStopping·Passing·Headlight | 설계속도 기준 정지·추월·전조등 시거에 필요한 최소 K (Civil 3D 값) |
| highestDesignSpeed | 이 곡선 구간에 적용된 최고 설계속도 |

- 볼록·오목은 crestOrSag로 판단하고, 경사 차 부호로 다시 판단하지 않는다.
- k가 minimumKStopping보다 작으면 "정지시거 기준 최소 K보다 작다"고 사실대로 밝힌다. 기준 만족 여부의 최종 판단은 사람이 한다.
- 최소 K 값이 비어 있으면 설계속도 기준이 적용되지 않은 종단이다. 추정하지 않는다.
- minimumK… 값은 Civil 3D 설계 기준 파일의 값이다. 법령(도로구조규칙)의 종단곡선 최소 변화 비율·최소 길이·최대 종단경사와 비교하라는 질문은 설계기준 규칙을 따르며(check_profile_criteria), 두 결과를 구분해서 답한다.

## 6. VIP(pvis)
- 각 항목: 번호, 측점, 표고, 들어오는·나가는 경사, 경사 차(나가는 − 들어오는), 곡선 종류(curveType), 곡선 길이, K, 볼록·오목, 시거(stopping·passing·headlightSightDistance).
- 첫 VIP에는 들어오는 경사가, 마지막 VIP에는 나가는 경사가 없을 수 있다.
- VIP 표고는 경사선이 만나는 점의 표고다. 종단곡선이 있으면 실제 종단선은 VIP를 지나지 않으므로, VIP 측점의 계획고를 물으면 elevations로 읽는다.

## 7. 표고(elevations)
- 특정 측점의 표고·경사는 elevations로 읽는다. VIP 사이를 직접 보간하지 않는다.
- stations를 주면 그 측점들을, interval을 주면 범위(없으면 종단 전체)를 그 간격으로 읽는다. 한 번에 200개까지다.
- elevation이 비어 있으면 그 측점은 종단 범위 밖이다. "종단 범위 밖"이라고 답한다.
- 계획고와 지반고의 차(절토·성토고)를 물으면 계획 종단과 지표면 종단을 같은 측점으로 각각 읽어 뺀다. 이 값은 "계산값"이라고 밝힌다.

## 8. 최고점·최저점
- 개요의 highest·lowest는 경사 구간 끝점과 곡선의 정점·최저점 중에서 찾은 값이다. 측점과 표고를 함께 답한다.

## 9. 종단도(views)
- 종단도는 종단을 보여 주는 그림이며 데이터가 아니다. 이름, 측점 범위, 표고 범위만 답한다.
- 종단도에 표시된 라벨, 밴드 내용, 관로 등 다른 객체는 아직 읽지 않는다.

## 10. 설계 기준 검사(design_checks)
- settings.useDesignCheckSet이 false면 "검사 세트가 지정되지 않아 확인할 수 없음"이라고 답하고, "기준을 만족한다"고 답하지 않는다.
- 항목은 검사를 통과하지 못한 경사 구간이나 곡선과 실패한 검사 이름이다. 최종 판단은 사람이 한다(핵심 규칙 6).

## 11. 읽지 못하는 것
- 개요의 unavailable에 있는 묶음은 Civil 3D가 값을 주지 못한 것이다. 그 내용은 "읽지 못함"으로 답한다.
