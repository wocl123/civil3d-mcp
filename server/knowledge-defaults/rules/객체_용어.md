# 객체 종류 한국어 용어

도구는 객체 종류를 .NET 클래스 이름으로 돌려준다. 사용자에게는 아래 용어를 쓰고, 처음 한 번만 괄호에 원래 이름을 붙인다. 예: 선형(Alignment) 2개.
표에 없는 종류는 원래 이름을 그대로 쓰고 뜻을 추측하지 않는다.

## AutoCAD 객체
| 종류 | 용어 |
| --- | --- |
| Line | 선 |
| Polyline | 폴리선 |
| Polyline2d | 2D 폴리선(구형) |
| Polyline3d | 3D 폴리선 |
| Arc | 호 |
| Circle | 원 |
| Ellipse | 타원 |
| Spline | 스플라인 |
| DBPoint | 점 |
| DBText | 문자(한 줄) |
| MText | 여러 줄 문자 |
| BlockReference | 블록 참조 |
| Hatch | 해치 |
| RotatedDimension, AlignedDimension 등 *Dimension | 치수 |
| Leader, MLeader | 지시선 |
| Table | 표 |
| RasterImage | 래스터 이미지 |
| Solid3d | 3D 솔리드 |
| Region | 영역 |
| Wipeout | 가림 영역 |

## Civil 3D 객체
| 종류 | 용어 |
| --- | --- |
| CogoPoint | COGO 포인트 |
| Alignment | 선형 |
| Profile | 종단 |
| ProfileView | 종단도 |
| TinSurface | TIN 지표면 |
| GridSurface | 그리드 지표면 |
| TinVolumeSurface, GridVolumeSurface | 체적 지표면 |
| Corridor | 코리더 |
| FeatureLine | 피처 라인 |
| SampleLineGroup, SampleLine | 샘플 라인(횡단 측선) |
| SectionView | 횡단도 |
| Network | 관망(파이프 네트워크) |
| Pipe | 관 |
| Structure | 구조물(맨홀·집수정 등) |
| PressurePipeNetwork, PressurePipe | 압력 관망, 압력관 |
| Parcel | 필지 |
| Assembly, Subassembly | 어셈블리, 서브어셈블리 |
| Intersection | 교차로 |
