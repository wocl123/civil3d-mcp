# 선형 해석 규칙

모든 값은 Civil 3D가 계산해 둔 값을 읽은 것이다. 같은 값을 다시 계산하지 않는다. 도구가 주지 않는 값을 계산했다면 "계산값"이라고 밝힌다.

## 1. 조회 순서
1. 선형이 무엇이 있는지는 list_alignments로 답한다.
2. 한 선형을 자세히 볼 때는 이름을 알면 list_alignments 없이 바로 get_alignment를 부른다. 개요에는 묶음(section)별 항목 수, Civil 3D가 주지 못한 부분(unavailable), 종단 목록(profiles), 설계속도(designSpeeds), 곡선이 30개 이하면 곡선(curves)까지 있다.
3. 개요에 없는 묶음만 get_alignment_section으로 읽는다. 특정 구간을 물으면 fromStation·toStation(원래 측점 숫자)으로 범위를 좁힌다.

| 질문 예 | 읽을 묶음 |
| --- | --- |
| 곡선이 몇 개, 각 곡선의 R | curves |
| 곡선 하나의 교각, 접선장, IP 좌표, A | elements (그 곡선 구간만) |
| BC·EC 같은 주요 점 측점과 좌표 | key_points |
| 측점이 중간에 바뀌는지 | station_equations |
| 편경사 | superelevation |
| 설계속도 | design_speeds |
| Civil 3D 검사 세트 위반 | design_checks |
| 법령 기준 만족 여부 | check_alignment_criteria (설계기준 규칙) |
| 종단, 샘플라인 그룹, 오프셋 선형 | related |

- 이름이 같은 선형이 여러 개면 핸들로 구분하고 사이트 이름을 함께 밝힌다.
- totalCount가 limit보다 크면 다음 페이지가 있다. 답에 필요할 때만 offset을 늘려 더 읽는다.

## 2. 선형 종류
| 종류 | 용어 | 해석 |
| --- | --- | --- |
| Centerline | 중심선 | 도로·하천 등의 주 선형일 가능성이 크다 |
| Offset | 오프셋 선형 | 다른 선형에서 떨어진 보조 선형. 기준 선형과 거리는 offset 묶음에 있다 |
| CurbReturn | 연석 회전부 | 교차로 모서리의 보조 선형 |
| Utility | 유틸리티 선형 | 관로 등 시설물용 선형 |
| Rail | 철도 선형 | 궤도 중심. 편경사 대신 캔트를 쓴다 |

- 본선과 램프·연결로의 구분은 종류로 알 수 없다. 이름과 사용자 답으로 확인하고, 확인되면 도면별 지식에 기록한다.

## 3. 측점과 측점 방정식
- 측점은 숫자(원래 측점, 시점에서 잰 거리)와 문자(…StationText)로 함께 온다. 사용자에게는 문자를 그대로 쓴다. 문자에는 도면의 측점 표기 설정과 측점 방정식이 반영되어 있다.
- 측점 숫자로 범위를 지정하거나 거리를 계산할 때는 원래 측점 숫자를 쓴다. 측점 문자끼리 빼서 거리를 구하지 않는다.
- station_equations에 항목이 있으면 측점 방정식이 있는 선형이다. 그 지점에서 표기 측점이 StationBack에서 StationAhead로 바뀌며, Type이 Decreasing이면 그 뒤로 측점이 줄어든다. 이때 연장은 length만 쓰고, 종점 표기 측점에서 시점 표기 측점을 빼지 않는다.
- 측점은 시점에서 진행 방향으로 커진다. 좌·우는 진행 방향 기준이다.
- 측점을 다른 표기(예: 20 m 간격 No. 표기)로 바꾸는 것은 사용자나 도면별 지식이 그 표기를 쓴다고 했을 때만 한다.

## 4. 곡선(curves)
- curves의 한 행이 곡선 하나다. 완화곡선-원곡선-완화곡선처럼 이어진 요소 묶음도 곡선 하나로 센다. 곡선 개수를 물으면 curves의 개수로 답하고, 요소 수로 세지 않는다.
- groupType은 묶음 구성이다: Arc(단곡선), SpiralCurveSpiral(완화-원-완화), SpiralSpiral(완화-완화), CurveReverseCurve(반향곡선) 등.
- turn: right는 우회전, left는 좌회전, mixed는 한 묶음 안에서 방향이 바뀐다.
- minRadius는 묶음 안 원곡선의 최소 반경, totalDeltaDeg는 묶음 전체 교각(도)이다.
- 최소 곡선반경을 물으면 curves의 minRadius 중 가장 작은 값과 그 곡선의 측점 구간을 답한다.

## 5. 요소(elements)
| kind | 용어 | 읽는 값 |
| --- | --- | --- |
| Line | 직선 | 길이, azimuthDeg(도면 Y축을 북으로 한 시계 방향 방위각) |
| Arc | 원곡선 | radius, turn, deltaDeg(교각), tangent(접선장 T), external(외할 E), midOrdinate(중앙종거 M), chord(현장), center, piPoint·piStationText(IP) |
| Spiral | 완화곡선 | spiralA(파라미터 A), radiusIn·radiusOut, spiralDefinition(Clothoid 등), spiralInOut(in = 원곡선으로 들어감), spiralK, spiralP(이정량), longTangent·shortTangent, piPoint(완화곡선 교점) |

- radiusIn 또는 radiusOut이 비어 있으면 그쪽은 직선과 이어진다(반경 무한대).
- curveGroup은 몇 번째 곡선 묶음에 속하는지다. 0이면 곡선이 아닌 직선이다.
- 좌표(startPoint, endPoint 등)는 [X, Y] 도면 좌표다.

## 6. 주요 점(key_points)
Civil 3D가 계산한 점을 측점과 좌표로 준다. 기본 용어는 아래와 같다. 회사가 다른 약어를 쓰면 이 표의 "답에 쓸 이름"을 고쳐 쓴다.

| Type | 의미 | 답에 쓸 이름 |
| --- | --- | --- |
| BegOfAlign | 선형 시점 | BP |
| EndOfAlign | 선형 종점 | EP |
| PI | 교점 | IP |
| TanCurve | 직선 → 원곡선 | BC |
| CurveTan | 원곡선 → 직선 | EC |
| TanSpiral | 직선 → 완화곡선 | TS |
| SpiralCurve | 완화곡선 → 원곡선 | SC |
| CurveSpiral | 원곡선 → 완화곡선 | CS |
| SpiralTan | 완화곡선 → 직선 | ST |
| CurveCompCurve | 복합곡선 접속점 | 복합곡선 접속점 |
| CurveRevCurve | 반향곡선 접속점 | 반향곡선 접속점 |
| TanTan | 곡선 없이 직선끼리 만나는 점 | 절점 |
| SPI | 완화곡선 교점 | 완화곡선 IP |

- 완화곡선 점(TS, SC, CS, ST)을 KA·KE 같은 국내 약어로 부를지는 회사 규칙으로 정한 뒤 이 표를 고친다. 정해지기 전에는 위 이름에 의미(예: "SC(완화곡선→원곡선)")를 붙여 쓴다.
- 표에 없는 Type은 원래 이름을 그대로 쓴다.

## 7. 편경사(superelevation)
- 개요의 settings.superelevationType이 NotSupported거나 superelevation 항목이 0개면 "편경사가 계산되어 있지 않음"이라고 답하고 추정하지 않는다. Cant면 철도 캔트이며 지금은 읽지 않는다.
- 각 항목은 편경사 곡선(curveName)의 주요 측점이다: BeginNormalCrown(정상횡단 시작), EndNormalCrown(정상횡단 끝), LevelCrown(편구배 0), ReverseCrown(반대편 경사가 같아지는 점), BeginFullSuper(전편경사 시작), EndFullSuper(전편경사 끝) 등. region은 In(곡선 진입부), Out(곡선 진출부)이다.
- 차로 경사는 % 단위다. leftOut·leftIn·rightIn·rightOut는 진행 방향 기준 왼쪽 바깥·왼쪽 안쪽·오른쪽 안쪽·오른쪽 바깥 차로다. 부호는 Civil 3D 기준으로 음수가 중심에서 바깥쪽으로 내려가는 경사다.
- 최대 편경사를 물으면 BeginFullSuper~EndFullSuper 구간 차로 경사의 절댓값 중 가장 큰 값을 답한다.

## 8. 설계속도(design_speeds)
- 각 항목은 적용 시작 측점과 값이다. 다음 항목의 측점까지 적용된다. 미터 단위 도면이면 km/h다.
- 항목이 없으면 "설계속도가 지정되지 않음"이라고 답한다. settings.useDesignSpeed가 false면 설계속도를 쓰지 않는 선형이다.

## 9. 설계 기준 검사(design_checks)
- settings.useDesignCheckSet이 false면 기준 검사를 쓰지 않는 선형이다. 이때 "기준을 만족한다"고 답하지 않고 "검사 세트가 지정되지 않아 확인할 수 없음"이라고 답한다.
- design_checks의 항목은 검사를 통과하지 못한 요소와 실패한 검사 이름이다. 항목이 0개고 검사 세트가 있으면 "지정된 검사 세트 기준으로 위반 없음"이라고 답한다.
- 설계 기준을 만족하는지 최종 판단은 사람이 한다(핵심 규칙 6).
- 법령 기준값(최소 곡선반경, 최대 편경사 등)과 비교하라는 질문은 설계기준 규칙을 따른다(check_alignment_criteria). Civil 3D 검사 세트 결과와 법령 비교 결과는 구분해서 답한다.

## 10. 연결 객체(related)와 오프셋(offset)
- related에는 이 선형의 종단 목록, 종단도 수, 샘플라인 그룹 이름, 이 선형을 기준으로 한 오프셋 선형 이름이 있다. 종단 해석은 종단 규칙을 따른다.
- offset에는 기준 선형 이름·핸들, 기준 오프셋 거리, 방향(Left/Right)이 있다. 확폭 구간은 아직 읽지 않는다.

## 11. 읽지 못하는 것
- 개요의 unavailable에 있는 묶음은 Civil 3D가 값을 주지 못한 것이다. 그 내용은 "읽지 못함"으로 답한다.
- 확폭(오프셋 선형의 구간별 폭 변화), 철도 캔트, 선형 라벨 내용은 아직 읽지 않는다.
