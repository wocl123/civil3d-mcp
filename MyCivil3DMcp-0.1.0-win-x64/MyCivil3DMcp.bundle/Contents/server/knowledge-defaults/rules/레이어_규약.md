# 레이어 규약

이 파일은 회사·팀 기준으로 사람이 채운다. 아래 표의 비고가 "예시"인 행은 형식을 보여 주기 위한 것이므로 판단에 쓰지 않는다.
표가 비어 있는 동안 AI는 레이어 이름만으로 의미를 단정하지 않는다(핵심 규칙 3).

## 회사 규약
| 레이어 이름 또는 패턴 | 내용 | 비고 |
| --- | --- | --- |
| C-ROAD-CL | 도로 중심선 | 예시 |
| C-TOPO-* | 현황 지형 | 예시 |
| *-TXT | 문자 | 예시 |

## 대부분의 도면에 해당하는 관례 (그래도 객체로 확인한다)
- "0"과 "Defpoints"는 AutoCAD 기본 레이어다.
- 이름에 OLD·DEL·삭제·폐기·TEMP·임시·참고·REF·검토가 들어가면 현행이 아닐 수 있다(핵심 규칙 5).
- 외부참조로 들어온 레이어는 "참조파일이름|레이어" 형식이다. 지금은 외부참조 안의 객체를 읽지 못한다.
